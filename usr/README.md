# Desktop Note App

A beautiful, responsive desktop-class note-taking application built with Flutter.

## Overview
This application provides a seamless note-taking experience for Desktop and Web platforms. It automatically adapts to mobile constraints with a dedicated layout, ensuring your notes are accessible everywhere. 

## Features
*   **Responsive Layout:** Features a two-pane layout (sidebar + editor) on desktop and a clean list-to-detail navigation pattern on mobile screens.
*   **Live Editing:** Note changes are instantly reflected in the sidebar list.
*   **Theming:** Automatically respects system dark/light mode preferences.
*   **Simple Management:** Easily create, edit, and delete text-based notes.

## Tech Stack
*   **Framework:** Flutter
*   **Language:** Dart
*   **State Management:** Core Flutter `StatefulWidget`

## Setup and Run
1.  Ensure you have Flutter installed.
2.  Clone this repository.
3.  Run `flutter pub get` to install dependencies.
4.  Run the application with `flutter run -d <windows|macos|linux|chrome>`.
